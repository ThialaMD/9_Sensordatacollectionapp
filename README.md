
### 📂 Exercise 09: Data Collection Android Application

**Type:** Mobile Development & Data Analytics 

**Language:** Java (Gradle build system, JDK 17) / Python (Jupyter Notebook) 

**Description:** Building, deploying, and utilizing a native Android client application designed to interface directly with the backend infrastructure to collect and analyze physical sensor metrics.

**Tasks Completed:**

**App Deployment:** Cloned, compiled, and built the native Android app using the Gradle build system (JDK 17) to generate and install the debug APK.

**Data Acquisition & Pipeline:** Orchestrated a live data collection workflow by selecting dynamic sensor arrays on a physical device, capturing the telemetry stream, and exporting/storing the data structure natively into a JSON file.

**Backend Integration:** Successfully uploaded the gathered sensor payload from the client app to the centralized data collection web service.

**Data Analytics:** Conducted exploratory data analysis on the extracted sensor outputs using exploratory data science environments (Python).
